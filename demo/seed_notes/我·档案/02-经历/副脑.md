# 副脑

**一句话**：一套工具，让任何人把自己或任何一个领域快速变成**可被 agent 调用的知识库**，并让这些知识库之间能互相通信。工作名「副脑」是你的原词，正式命名待定。

- **时间**：2026 年 8 月起，构想与申请阶段
- **团队**：你 + 一位神经科学方向在行的队友（**姓名待补**）
- **状态**：计划先交一份申请，通过了再决定去不去（申请对象**待补**）

## 背景：问题是什么（你 [phone] 的口述）

大模型是通用的，但不是「你的」。让它写一份实习申请，写出来不会好，因为它根本不了解你；当场喂信息给它，代价是烧掉大量上下文，整体体验很差，而且下次对话归零。Obsidian 这类工具适合当**人的**存储库，但它的结构不是为 agent 调用设计的。

你的判断：需要一种 agent 可调用的形态，把你自己变成一个信息库，让 AI 随时取用。副脑不只是「关于我的」，也可以是一个项目的进展记录、一本学习词典（比如 AI 术语），可以建很多个。

## 产品形态（三层）

1. **快速搭建**：低成本起一个副脑。不是又一个笔记软件，是「约定生成 + 摄入循环」
2. **约定层**：每个副脑有一份机器可读的宪法（格式、分类、关联规则、出处要求），靠脚本校验而不靠自律
3. **脑间通信**：多个副脑互相查询与引用

**为什么是多个副脑而不是一个大库**（Claude 的推演，你未否认）：不同领域需要不同 schema，你自己的四个库就是证据（知识点库、论文实验库、论证库、个人档案库，格式互不相容）。所以「脑间通信」不是锦上添花，是分库的必然结果。

## 神经科学切入

你的定位：用大脑 / 神经科学切入，**因为队友在这方面在行**。

Claude 给的可用借鉴（记忆架构层面，队友把关措辞）：语义记忆与情景记忆分开存、检索方式不同；inbox 到 topic 的消化即记忆巩固；遗忘是特性不是缺陷；人靠线索唤起记忆，agent 靠什么。

一句必须记住的提醒：**神经影像（fMRI、EEG）是测量方法，和「借鉴大脑的记忆架构」不是一回事。** 申请要的是前者就是硬凑，要的是后者上面四条站得住。

## 已写材料

一段式项目总览（你要的最终版，[phone]）：

> 人和大模型协作时最反复出现的挫败，是它不了解你：让它写一份申请或一封邮件，写出来的东西泛泛而空，而当场补背景既烧上下文又无法累积，下次对话重新归零。从神经科学的角度看，这不是模型不够聪明，而是它缺一套长期记忆系统：大脑并不把一切都留在工作记忆里，而是把情景经验巩固为语义结构、建立索引、主动遗忘、再由线索唤起；今天的大模型几乎只有工作记忆，也就是上下文窗口，因此每次对话都从失忆开始。我们做的「副脑」就是把这套缺失的系统外置出来：一个让人低成本地把自己、一个项目或一个知识领域，转化为 agent 可随时调用的结构化长期记忆的工具。它为每个副脑生成机器可读的组织约定、强制记录每条信息的出处、并把零散材料持续消化进长期结构；又因为不同领域需要不同的组织方式，正如大脑的记忆系统本身是分化而互联的，我们同时提供副脑之间互相查询与引用的协议。这套约定我们已在四个真实的个人知识库上手工验证过。
