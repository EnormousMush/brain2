# Pascu 2026

**定位**：Echoes:语义对齐音乐深伪数据集——同 prompt 协议的撞车方,论文必引

**《Echoes: A Semantically-Aligned Music Deepfake Detection Dataset》(Pascu, Oneata, Cucu, Müller, arXiv 2603.23667,2026-03)——"内容对齐防捷径"的首发方,与我们冻结 prompt 协议同哲学、早四个月。**

#### 数据集
拿**真实波形/歌曲描述当条件**生成配对假货 → 真假在内容层面对齐;明确动机:
**防捷径学习、逼检测器学可迁移线索**。10 个流行生成系统,4,468 首 / 131 小时,多流派。
三个发现:Echoes 是现有最难的数据集;别处训练的检测器泛化到它很差;
用它训练得到最强跨数据集泛化。
血统注:二作 Oneata 与 [[Smeu 2025]] 同组(罗马尼亚捷径研究一脉)。

#### 与我们的关系(诚实盘点)
- **撞车部分**:"对齐内容分布防捷径"的宣称首发权是他们的——论文必引,
  且从"我们发明了这个协议"改口为"与 Echoes 同哲学的更强版本";
- **我们仍独有的**:①逐条同 prompt 的严格配对(1000×8 genre 均衡,对齐粒度更细);
  ②14 家版图含商用盲盒(Mureka/Udio)与同实验室对照对(DR1/DR2);
  ③家族转移矩阵 + 指纹考古 + 编码器共振——他们停在"数据集难",我们解剖"为什么难";
- **好消息**:审稿人不能再质疑同 prompt 协议是自嗨——领域已认这个方法论;
  且 Echoes 可以当我们的**外部测试集候选**(严格 test-only,同 SONICS 规矩)。
