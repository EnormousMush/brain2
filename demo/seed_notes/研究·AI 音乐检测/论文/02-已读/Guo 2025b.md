# Guo 2025b

**STARS: A Unified Framework for Singing Transcription, Alignment, and Refined Style Annotation** · Wenxiang Guo, Yu Zhang, Changhao Pan, Zhiyuan Zhu, Ruiqi Li 等（浙江大学，Zhou Zhao 通讯）· ACL 2025 Findings · https://aclanthology.org/2025.findings-acl.781/ · https://arxiv.org/abs/2507.06670

注：文件名的 b 后缀是为了和 `Guo 2025`（TechSinger）区分，两篇是同一位一作 Wenxiang Guo 的同年两篇。

## 它做了什么

标注自动化那条线的最后一块拼图。前面几篇的自动标注只覆盖了「唱什么」和「唱在哪个音上」，**「怎么唱」一直靠人工**。STARS 四样全包。

| | 音素对齐 | 音符 | 技巧 | 全局风格 |
|---|---|---|---|---|
| GTSinger | 人工修 | 人工修 | 人工 | 人工 |
| TechSinger | | | 自动 | |
| SoulX-Singer | 自动 | 自动 | | |
| **STARS** | **自动** | **自动** | **自动** | **自动** |

TCSinger 2 的 limitations 里明写「仍依赖人工标注的风格标签」，STARS 就是那句话的答案，而且是同一个组、同一年。

**它对现有做法的批评**：现有方案依赖碎片化的工具链，用 WhisperX、Qwen-Audio 做歌词转写，MFA 做强制对齐，VOCANO、MusicYOLO 做音高，由此引入工具之间不匹配造成的级联误差。**而这正是 SoulX-Singer 那条流水线的做法**（SenseVoice 到 Paraformer 到 ROSVOT）。STARS 早了八个月，SoulX-Singer 仍选碎片化路线，因为它要处理 42,000 小时，工程上串联现成工具比训一个端到端模型省事得多。研究口味与工程现实的分歧，两边都说得通。

**结构**：输入梅尔谱，五级层次（帧、词、音素、音符、句）。局部声学编码器用 U-Net 加 Conformer 块加 FreqMOE，向量量化做多级特征提取，然后是顺序预测流水线：音素边界、音符边界、音高、音素级技巧、全局风格。关键是端到端联合优化而不是把几个独立模型串起来。

训练数据是 GTSinger 的中英子集加一个 30 小时的中文数据集（两位歌手），**跟 TechSinger 自采的那 30 小时是同一批**。

## 结论

**九种技巧的识别成绩（Table 3）。** 技巧从 GTSinger 的六种扩到九种：原来的混声、假声、气声、咽音、颤音、滑音，加上 TechSinger 引入的气泡音，再把强度拆成强、弱两类。

| 技巧 | F1 | 准确率 | 差 |
|---|---|---|---|
| 强 Strong | 99.4 | 93.9 | -5.5 |
| 假声 Falsetto | 93.5 | 94.7 | 1.2 |
| 弱 Weak | 90.3 | 90.4 | 0.1 |
| 咽音 Pharyngeal | 85.0 | 95.4 | 10.4 |
| 混声 Mixed | 74.7 | 81.9 | 7.2 |
| 滑音 Glissando | 72.3 | 84.1 | 11.8 |
| 气泡音 Bubble | 71.7 | 97.8 | **26.1** |
| 气声 Breathy | 66.9 | 88.8 | 21.9 |
| 颤音 Vibrato | 65.5 | 96.7 | **31.2** |
| **平均** | **79.9** | **91.5** | |

**F1 与准确率的分歧在稀有技巧上又出现了。** 气泡音准确率 97.8 而 F1 只有 71.7，颤音准确率 96.7 而 F1 只有 65.5。原因跟 GTSinger 那次一样：这些技巧太稀有，模型无脑猜「没有」就能刷高准确率，F1 才戳穿它。**这是同一条研究线上第三次出现（GTSinger、TechSinger、STARS），可以确认不是偶然，而是音素级稀有标签任务的固有性质。** 见 [[evaluation-metrics]]。

**跟 GTSinger 的数字核对**：混声 0.78 对 74.7、假声 0.96 对 93.5、咽音 0.85 对 85.0、颤音 0.70 对 65.5、滑音 0.70 对 72.3 都接近，**但气声是 0.99 对 66.9，差 32 个点**。同一个组、同样的技巧定义却在同一个技巧上差这么多，只能是测试集划分或标注口径不同。**这又是跨论文数字不可直接比的实例，而且这次是同组内部。**

**另外两项任务：**

| 任务 | 基线 | 基线成绩 | STARS |
|---|---|---|---|
| 歌词对齐 | MFA | BER 40.3 / IOU 56.8 | **BER 18.6 / IOU 80.9** |
| | SOFA | BER 20.9 / IOU 80.0 | |
| 音符转写 | VOCANO | COnPOff 50.2 / RPA 76.6 | **COnPOff 71.0 / RPA 86.7** |
| | ROSVOT | COnPOff 70.2 / RPA 83.8 | |

**对 MFA 的优势很大**（BER 从 40.3 降到 18.6，边界误差砍掉一半以上）。GTSinger 当年就是 MFA 粗对齐再人工修，这个数字说明那道人工修确实必要，也说明现在可以不修了。**但对 ROSVOT 的优势很小**（COnPOff 只多 0.8 个点），而 SoulX-Singer 那 42,000 小时的音符标注用的就是 ROSVOT，所以尽管 STARS 批评碎片化工具链，在音符转写这一项上 SoulX-Singer 用的工具其实已经接近 SOTA。

**全局风格属性的准确率只有 68.0**（情绪、速度、音域、语言、性别的平均），对比技巧识别的平均准确率 91.5 差了 23 个点。情绪这类东西本身主观，人标都未必一致。这意味着全局风格标签的自动化还不能完全替代人工，TCSinger 2 那条 limitation 只被部分解决。

**全篇最有力的一行是下游实验（Table 5）：**

| 训练用的标注 | MOS-Q | MOS-C |
|---|---|---|
| 人工标注 | 3.98 | 4.05 |
| STARS 自动标注 | 3.89 | 3.95 |

**差 0.09 和 0.10。** 这是整条标注自动化路线上最想知道的那个数字：用自动标注训出来的 SVS 模型，跟用人工标注训出来的到底差多少。前面几篇都在做自动标注，但没有一篇直接回答过这个问题。TechSinger 报了检测器 83.3% 的准确率但没说这会让最终模型差多少，SoulX-Singer 干脆没报标注准确率。**STARS 是第一个把「标注准确率到下游模型质量」这条因果链走完的。**

## 局限

- **下游那个 0.1 分是在小规模上测的。** 训练数据是 GTSinger 中英子集加 30 小时，不是 42,000 小时。规模拉大之后标注误差会不会累积，没有答案。
- **全局风格准确率 68.0 偏低**，而论文没有拆开报告情绪、速度、音域、语言、性别各自的准确率，因此不知道是哪一项拖后腿。
- **气声 F1 与 GTSinger 差 32 个点未被解释**，论文也没有跟自己组的前作做数字对齐。
- **没有规模化验证。** STARS 是一个标注器，但论文没有用它去标一批大规模数据并展示结果。精度更高、覆盖更全的方案没有规模化，而规模化了的方案（SoulX-Singer）精度不明。
- **训练数据只有 GTSinger 中英子集加 30 小时中文**，规模很小，而标注器的泛化能力恰恰依赖训练数据的覆盖面。九种技巧的识别成绩是在与训练数据同源的分布上测的。
- **与 TechSinger 的关系没有说明。** 同一位一作、同一年、同样做技巧识别，但论文没有把 TechSinger 的检测器列为基线，也没有解释两者的分工。

## 对我意味着什么

- **自动标注够不够用，答案是够（在这个规模上）。** 下游 MOS 只差 0.1，而人工标注的成本是每小时数十倍。**这是整条线上最该带给学姐的结论。**
- **F1 与准确率的分歧在稀有标签上是必然的，不是偶然。** 同一条研究线上三次出现。凡是音素级的稀有属性标注，只看准确率一定会被骗。这条已经可以当作方法论写进报告。
- **同组内部的数字也可能对不上。** 气声 F1 在 GTSinger 是 0.99、在 STARS 是 66.9。跨论文引用数字必须带出处和测试集，这条又被印证一次。
- **研究口味和工程现实会分岔。** STARS 批评碎片化工具链、主张端到端；SoulX-Singer 明知这个批评仍用碎片化，因为要处理 42,000 小时。两边都对，只是约束不同。**评价一个技术选择时要先问它在什么约束下做的。**
- **一个现成的空白：端到端标注器还没有被用在万小时级数据上。** 精度更高、覆盖更全的那个没规模化，规模化的那个精度不明。如果学姐的场景需要大规模精细标注，这既是风险也是机会。
- **「怎么唱」的自动化只补了一半。** 技巧识别平均准确率 91.5 够用了，全局风格 68.0 还不够。
