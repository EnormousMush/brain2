# Dao 2026

**定位**：表示层对抗式去混淆(梯度反转 + VIB)

**引用:** Dao, Matrouf, Rouvier, Evans, *Linguistic Bias Mitigation for Spoofing Detection via
Gradient Reversal and A Variational Information Bottleneck*, arXiv 2606.31411, 2026。
**混淆的"手术刀"篇:物理删不掉的混淆,从表示里对抗性地挤出去。**

#### 混淆现场:语言/文本内容当捷径
ASVspoof 5 里真假语音的**说话内容系统性不同**:SONAR 嵌入聚类显示真样本和假样本占据不同簇
(假样本聚成 8 个簇,正好对应 8 个 TTS 模型)——分类器顺手学了"听内容辨真伪",跨库就崩。
和我们的制作轴混淆同构:**混淆变量和标签在数据里纠缠,且没法从音频里物理删除**。

#### 方法:梯度反转 + 变分信息瓶颈
- **GRL(梯度反转层)**:接在 XLSR 特征后,连一个"猜语言内容"的对抗头;反传时梯度乘 −λ
  → 特征被逼得**让对抗头猜不出内容** = 语言信息被从表示里挤出去;
  (另有 Common Voice 训的冻结 teacher 提供内容参照嵌入);
- **VIB(变分信息瓶颈)**:在语言分支上加随机隐变量 + KL 正则——**防止挤过头**误删真正的
  伪造线索,控制"只压主导的语言信息"。

#### 结果(9 个数据集 pooled EER)
| 配置 | pooled EER |
| --- | --- |
| MHFA 基线 | 13.67% |
| + GRL(IVLing) | 9.56%(相对 −30%) |
| **+ GRL + VIB** | **8.72%(相对 −36.2%)** |
消融:VIB 单用 +1.84%、GRL 单用 +4.11%、合用 +4.95% → 两机制互补。
跨域:ITW 1.88%、ASVspoof19 4.07%;CodecFake 仍 20.28%(跨 codec 依旧难——各条路线在这上面都卡 ~20%)。

#### 对我们的意义
1. **工具箱补洞**:我们的消融三连全是"物理移除"(低通/重编码/EQ),但**制作现代度没法物理删除**
   ——GRL 给了第二条路:训练时对抗性惩罚"能分辨制作年代/生成器"的特征方向;
2. 落地设计见 混淆对抗训练(我们的方法笔记)——**对音乐深伪做混淆对抗训练,没人做过**;
3. VIB 的"防挤过头"设计回答了关键担忧:对抗去混淆可能把真指纹一起删掉——他们的消融证明
   可以控制这个 trade-off。
