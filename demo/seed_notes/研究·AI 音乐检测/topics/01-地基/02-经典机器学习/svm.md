# svm

**一句直觉：分界线不光要分开，还要离两边尽量远**

SVM 的直觉是，分界线不仅要把两类分开，还要离两边最近的点尽可能远（留足 margin/安全区）。这样对新数据更稳，不会因为一点点噪声就翻车。

**软间隔：允许少数点越界，用 C 控制严格程度**

现实数据很少完美线性可分，所以 SVM 允许少数点越界，用一个参数 C 控制「要多严格」。C 越大越不容忍犯规，越容易死记硬背、过拟合；C 越小越宽容，分界面越平滑。

**核技巧：把数据甩到高维再切**

线性分不开时，可以把数据想象成「甩」到更高维空间里再找分界面（二维分不开的两个同心圆，甩到三维就能用一个平面切开）。核函数就是省去「真的把每个点映射过去」这一步庞大计算量的技巧，直接算出高维空间里的「距离感」。注意这和 [[activation-function]] 的逐元素操作性质完全不同：核函数是升维，激活函数不升维、只原地掰弯数值。

**只认支持向量**

最后 SVM 只认「离分界线最近的那几个点」（支持向量），其他点删掉重训结果都不变。这跟 [[logistic-regression]]「每个点都参与决策」是很不一样的性格，根源在它用的是 hinge loss（分对且够自信就完全不管了，见 [[loss-functions]]）。

**一句话总结**：SVM 追求「最大间隔」的稳健分界，用 C 权衡严格度、用核函数在高维里切开非线性数据，而 hinge loss 让它最终只依赖少数支持向量，这是它和逻辑回归最本质的性格差异。
