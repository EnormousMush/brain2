# tree models

**一句直觉：不停问「哪个问题最能把两类分开」**

决策树就是不断问「能把两类分得最开」的问题，像医生排查病情一样一层层问下去，问到每个格子里的样本基本同类就停。单棵树的毛病是极易过拟合：问题问到极细，把训练数据每个细节都记住，换一批新数据就懵。治法是限制树的深度，或者先长满再剪掉不划算的分支。

**随机森林：独立 + 投票，降方差**

随机森林是「很多人各自随便看一部分数据和一部分角度，分别做判断，最后投票」。大家互相独立，就能抵消个体的极端错误。只要树和树之间足够不像（靠随机抽数据 + 随机抽特征做到），平均下来就比任何单棵稳，这叫降方差。而且每棵树互不依赖，可以同时训练，速度快。

**GBDT：接力 + 纠错，降偏差**

GBDT 的思路完全相反：一条链，第一个人先随便猜个大概，下一个人专门看前面错在哪、错多少，针对性纠正，再下一个接着纠。因为后面的人必须知道前面所有人的结果才能干活，所以没法并行。它靠步步小修小补逼近答案，每步都故意走得很小心（学习率调小），单棵树也故意设计得很弱很浅，靠人多凑出一个强整体，这叫降偏差。

一句话记区别：随机森林靠「独立+投票」求稳，GBDT 靠「接力+纠错」求准。

**和深度学习的对比**

树模型在表格数据上至今打得过深度学习，因为它天生能处理异构特征、还不需要 [[normalization]]。这一点和 [[neural-network]] 形成有意思的对照：并不是所有场景深度学习都赢。

**一句话总结**：决策树靠不断分裂逼近纯净，随机森林用独立投票降方差、GBDT 用接力纠错降偏差，而树模型在表格数据上对深度学习的持续优势，来自它对异构特征的天然友好。
