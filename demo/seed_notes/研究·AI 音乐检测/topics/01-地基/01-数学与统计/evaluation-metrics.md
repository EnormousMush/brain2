# evaluation metrics

**① 核心观念:没有"最好"的指标,只有"最匹配你场景"的指标**

关键不是找一个万能指标,而是问自己:**在我的场景里,哪一类错误更致命?** 两类错误的代价往往天差地别,谁致命就盯谁。

---

**② Precision vs Recall:两种错误,两把尺子**

先分清检测器犯的两类错(对应你 EER 笔记里的 FAR/FRR):

**看 precision(精确率)的场景——"宁可漏判,也别错杀好人"**

precision 关心的是:**我判为"阳性"的里面,有多少是真的?** 当**错杀好人代价极高**时看它。

- 例子:**垃圾邮件过滤**。把一封重要邮件误杀进垃圾箱(错杀),代价远比漏掉几封垃圾邮件严重。所以宁可放几封垃圾邮件进来,也别误删正经邮件 → 盯 precision。

**看 recall(召回率)的场景——"宁可错杀,也不能放过坏人"**

recall 关心的是:**所有真的"阳性",我抓到了多少?** 当**漏掉一个真目标代价极高**时看它。

- 例子:**癌症筛查**。漏掉一个真病人(漏判)可能要命,而多让几个健康人去复查只是麻烦。所以宁可多抓错、多复查,也绝不能漏掉真病人 → 盯 recall。

**③ 它俩是跷跷板**

这是最关键的直觉:**precision 和 recall 天生对立**。你想让模型更"敏感"、多抓一些(recall↑),它通常就会**跟着多抓错一些**(precision↓);反之亦然。**你没法同时把两个拉满**,只能按场景取舍。

**F1** 就是给"两者都不能太差"的场景准备的**折中点**——它是 precision 和 recall 的调和平均,逼你在两边都保持体面,任何一边烂了 F1 都会被拖下去。

---

**④ 最大的坑:数据不平衡时,Accuracy 会骗你**

这条是重点中的重点。**当正样本极少时,Accuracy(准确率)是个骗子。**

例子:某病发病率只有 **1%**。一个**什么都不学、无脑猜"没病"**的废物模型,准确率也有 **99%**(因为 99% 的人本来就没病)。数字漂亮得很,但这模型**一个真病人都没查出来,毫无用处**。

遇到这种不平衡场景:

- **别看 Accuracy**——它被多数类撑得虚高。
- **改看 precision / recall**,或专门为不平衡设计的 **PR 曲线**。
- **连 ROC 也要小心**——ROC 在**正样本极少时容易掩盖问题**,让模型显得比实际更好。这时 PR 曲线比 ROC 更诚实。

(这条正好解释了你 EER 笔记里"accuracy 全猜多数类会虚高"那句——同一个坑的展开。)

**⑤ 语音生成的四把尺子:测的是四件不同的事

上面几条讲的是分类和检测。生成任务(TTS、歌声合成、语音转换)有另一套常用指标,**它们量的是完全不同的维度,而且会互相打架**:

- **WER(词错误率)** ↓ :把合成语音丢给 ASR 转录,再和原文比对。`WER = (S + D + I) / N`,分别是替换、删除、插入的词数和参考文本总词数。量的是**可懂度**,字有没有说对说清楚。3% 算很好,13% 已经明显吞字,89% 等于 ASR 根本转不出来。
- **SIM(说话人相似度)** ↑ :用说话人验证模型分别从参考音频和合成音频里提取 speaker embedding,算余弦相似度。量的是**像不像本人**,和说了什么无关。通常分 seen / unseen 两栏报,unseen 那栏才是真正的零样本能力。
- **UTMOS** ↑ :MOS 是找人打 1 到 5 分的主观音质评分,请人太贵,于是训练一个模型去预测人会打多少分。量的是**好不好听**。
- **SR(成功率)** ↑ :生成到一半崩掉、陷入无限循环、吐出噪音的样本算失败。量的是**能不能稳定产出**。

打架的例子很具体:同一个模型把多 token 预测的压缩比从 3 拉到 12,WER 从 5.84 降到 3.01(说得更清楚了),UTMOS 却从 3.83 掉到 3.67(音质变糙了)。所以这几个必须一起报,只挑赢的那个说就是耍流氓。这跟 ① 是同一个道理:先想清楚你的场景里哪类错误更致命。

**⑤ 跨论文比数字，比选错指标更危险**

前面讲的都是「在同一份数据上，该看哪个指标」。还有一层更常被忽略：**不同论文报的数字，往往根本不在同一个尺度上，直接横比会得出完全错误的结论。**

一个真实的例子。同一个歌声生成模型（Vevo2），在自己那篇论文里报的歌声 WER 是 7.66，在另一篇论文（UniVoice）当基线时报的歌声 PER 是 45.07。差了近六倍，但两个数都没错，因为三件事都不同：

- **指标不同**：WER 是词错误率，PER 是音素错误率，后者天然更严格
- **测试集不同**：一个用 GTSinger 加 SingStyle111，一个用论文自建的 UniSinging-Eval
- **甚至模型版本可能都不同**：那篇论文里同一个基线在摘要写 Vevo1.5、正文写 Vevo2

**实用规则：引用任何一个数字时，必须同时记下出自哪篇、哪个测试集、什么指标。** 缺任何一项，这个数字就只能在原论文内部横比，不能拿出来跟别处的数字放在一起。

论文自己也常常在这里出问题：把「我们的 PER 领先」和「我们的 SIM」并列成一句话说，而实际上只有前者领先、后者垫底。看表比看正文可靠。
