# vae

**一句直觉:训练一对「压缩器 + 还原器」,并且强迫中间那层压缩表示长得规整、连续、可以随机采样。**

**和普通 autoencoder 差在哪**

普通自编码器把输入压成**一个点**,只要求还原得像。结果是潜空间坑坑洼洼:训练样本落在的地方能还原,中间的空隙随便取一个点解码出来就是垃圾。所以它只能压缩,不能生成。

VAE 的改动是把输入编码成**一个分布**(输出均值和方差),再从这个分布里采样一个点送去解码,同时加一项 KL 惩罚把这些分布往标准高斯拉。两件事同时发生:

- 采样带来的抖动逼着解码器对「附近的点」都要输出合理结果,于是潜空间变**连续**,可以插值;
- KL 项把整个潜空间收拢到标准高斯附近,于是可以**直接从高斯采样再解码**,这才叫生成模型。

损失就两项:重建误差加 KL 正则。两者的配比是 VAE 最经典的调参痛点,KL 压太狠会「后验塌缩」(解码器干脆无视潜变量),压太松就退化回普通自编码器。

**重参数化技巧**

从分布里采样这个动作本身没法求导,梯度传不回编码器。解法是把随机性挪到外面:不直接采样 z,而是写成 z = 均值 + 标准差 × ε,其中 ε 从标准高斯采。这样随机的部分是与参数无关的 ε,均值和标准差这条路上梯度畅通,见 [[backprop]]。

**现代用法:VAE 很少单独当生成器,主要当压缩器**

直接用 VAE 生成图像或音频,结果通常偏糊,因为高斯假设加 KL 正则会抹掉高频细节。所以现在的主流用法是**分工**:VAE 只负责把高维数据压到一个低维、连续、规整的潜空间,真正的生成交给 [[diffusion]] 或 [[flow-matching]] 在这个潜空间里做。这就是 latent diffusion 的思路,好处是扩散过程的计算量从像素级降到潜空间级。

音频侧的实例:Oobleck VAE(ACE-Step v1.5 和 stable_audio 都用它)、Mel-VAE(audioldm2、musicldm、mustango 这一族先转 mel 谱再压)、DCAE。生成完潜表示之后还要过还原器出声,见 [[neural-vocoder]] 和 [[music-generation-pipeline]]。

**一个反直觉的实测发现**

honors 项目里量到:ACE-Step v1.5 和 stable_audio_open 用的是**同一款 Oobleck VAE**,但两者的鉴伪指纹并不聚在一起。结论是指纹由整条渲染管线的总效果决定,不由单个零件的血统决定。换句话说,「用了同一个 VAE」不足以让两个生成器长成一家人。

**一句话总结**:VAE 靠「编码成分布 + KL 拉向高斯 + 重参数化」把潜空间整理得连续可采样,现在主要不是当生成器用,而是当扩散和流匹配的低维工作台。
