# cnn rnn limits

CNN 局限在于感受野有限、需堆叠很多层或用 dilated conv 才能捕捉长距离依赖,且强局部归纳偏置(locality)在需要精确位置/全局关系建模的任务上是负担。

RNN 局限在于序列依赖导致训练推理必须逐步算、无法并行,且所有历史信息压缩进固定维度隐状态存在信息瓶颈。原始 RNN 还存在严重的长序列梯度消失/早期信息遗忘问题——LSTM 和 GRU 正是为缓解这一点提出的门控改良:

- **LSTM(Long Short-Term Memory,1997)**:门控 RNN 鼻祖,维护一条独立的 cell state(细胞状态)作为长期信息"传送带",信息可近乎无损地长距离流动;用遗忘门/输入门/输出门分别控制旧记忆丢弃、新信息写入、当前对外输出;梯度沿 cell state 平稳回传,大幅缓解梯度消失。
- **GRU(Gated Recurrent Unit,2014)**:LSTM 的简化版,砍成两门(更新门=合并遗忘+输入,重置门=控制忽略多少旧状态),去掉独立 cell state 并入隐状态;参数更少、更快、小数据不易过拟合,多数任务与 LSTM 打平。

但关键在于:门控只解决了"记不住(长程遗忘)",**没解决"必须逐步算、无法并行"这个 RNN 的根本硬伤**,长序列下依然会遗忘早期信息。所以 LSTM/GRU 缓解了梯度消失却仍受困于串行计算与信息瓶颈,RNN 这一整支最终仍被 Transformer 取代。

这些局限直接催生 Transformer——self-attention 用矩阵乘法直接建模任意两位置关系、不受距离限制,且可完全并行计算,一次性同时解决"记得住(任意距离)"和"能并行"两件事(代价是 O(n²) 复杂度)。
