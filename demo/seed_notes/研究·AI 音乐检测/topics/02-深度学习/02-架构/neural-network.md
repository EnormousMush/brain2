# neural network

**一句直觉：用三把尺子量所有架构**

看一个网络架构行不行，拿三把尺子量：能不能记住远处的信息、能不能并行、训练稳不稳。经典架构在这三把尺子下各有死穴。

**MLP / CNN / RNN 各自的问题**

- MLP（全连接）：没有顺序概念，而且输入定长。处理变长有序的文字直接出局。
- CNN：靠滑动卷积核看局部，主场是图像（局部像素→边缘→脸），能并行，但远距离关系要叠很多层才够得着，文字上不是最优。
- RNN：排队处理、逐字更新隐藏状态（一个记忆小本子），天生懂顺序，但有两个致命伤。一是长程依赖被冲淡（信息一棒一棒传，传远了就淡了，本质是 [[gradient-vanishing]]）；二是没法并行（第 n 个字依赖第 n-1 个字，只能串行，榨不出显卡的并行能力）。在大数据大算力时代，这基本判了死刑。LSTM/GRU 的门控只是缓解遗忘，治标不治本。

**Transformer 为什么赢**

[[transformer]] 靠三点翻盘：远距离一步到位（[[attention]] 让任意两个字直接两两算关联，开头和结尾 distance=1，不经中间转手）；完全可并行（所有字一起算、各计算互不依赖，榨干显卡，这是它能被训成「大」模型的根本）；配合残差连接和 [[batchnorm-layernorm]]（实际用的是 LN）可以稳定堆几十上百层。代价是 O(n²)，而 RNN 在这点上反而是线性。

[[ssm]]/[[gdn]] 这些新架构，本质就是想把 RNN 那种「线性带状态」的省钱思路请回来，同时保住 transformer 的并行和效果，在两者之间找更好的平衡点（归一化机制见 [[normalization]]，RNN 的局限详见 [[cnn-rnn-limits]]）。

**一句话总结**：用「记远处/能并行/训得稳」三把尺子看，MLP 输在变长、CNN 输在远距离、RNN 输在不能并行且梯度消失，transformer 三项全占赢下主流，而 SSM/GDN 正在为它那 O(n²) 的代价找替代。
