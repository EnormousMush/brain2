# optimizer

**一句直觉：一条「怎么迈步下山」的演进链**

优化器解决的是「拿到梯度后，往哪走、迈多大步」。从 SGD 到 AdamW 是一条清晰的演进链，每一步都在补上一步的坑。

**这条链具体怎么走**

- SGD：每步只看当前梯度定方向，步子大小固定。遇到狭长山谷会来回震荡。
- +Momentum：引入历史梯度的滑动平均（m = 0.9·m + 0.1·梯度），相当于给球加惯性，减少震荡、加速收敛。
- AdaGrad：给每个参数按「历史梯度平方的累加值」反比缩放学习率（动得多的步子变小、动得少的变大）。但累加只增不减，导致后期步子趋于 0，训练「僵住」。
- RMSProp：把 AdaGrad 那个无限累加换成指数滑动平均（v = 0.9·v + 0.1·梯度²），只参考近期梯度，避免步子无限衰减。
- Adam = Momentum（一阶矩 m，决定往哪走）+ RMSProp（二阶矩 v，决定迈多大步）。更新量 = 学习率·m/(√v+ε)，另加偏差修正，处理训练初期 m、v 从 0 累积导致的低估。
- AdamW：把权重衰减（L2 正则）从 Adam 的自适应步子计算里解耦出来，单独对参数做衰减，避免衰减力度被自适应步子稀释，效果更纯粹。现在训练 LLM/ViT 这类大模型基本标配 AdamW。

它消费的是 [[backprop]] 算出来的梯度，目标是把 [[loss-functions]] 给出的那个数字压小。

**一句话总结**：优化器是「怎么下山」的策略，从 SGD 一路加惯性、加自适应步长、再解耦权重衰减，演进到 AdamW，核心都在解决「步子方向和大小怎么定得又快又稳」。
