# normalization

**一句直觉：只调数值的尺度，不动维度**

归一化不改变数据的维度，它只调整数值的范围/尺度。做法是把一批数 (x - 均值) / 标准差，再乘一个可学习的缩放 γ、加一个可学习的偏移 β。目的是让不同特征、不同来源的数值处在同一个量纲上，方便比较，也让训练更容易收敛。

**别和降维搞混**

关键是别把它和 PCA 这类「压缩维度」的操作混淆。归一化是「调尺度」，PCA 是「降维」，一个原地改数值、一个真的减少维度，完全两回事。这一点和 [[activation-function]] 强调的「不改变维度」是同一种提醒：这类操作只动数值，不动形状。

**γ 和 β 可以不是自由参数，而是别的东西算出来的**

标准归一化里 γ 和 β 是两个可学习的常数，训完就固定了。但它们也可以是某个条件向量的函数：给一个风格向量 s，用两个小网络算出 γ(s) 和 β(s)，再拿去调制归一化后的特征。这样一来，归一化层就从「统一量纲」变成了「注入条件」的通道，同一个网络喂不同的 s 就产出不同风格的结果。

图像领域管这叫 AdaIN（adaptive instance normalization），是风格迁移的常用武器。歌声合成里也在用：TCSinger 的 mel-style adaptive normalization 就是把 LayerNorm 的 γ 和 β 换成风格向量的函数，在扩散解码器的每一层都重新调制一次。这么做的动机是量化有损，相近的风格会被编码成同一个离散索引，只在输入端给一次条件不够，逐层调制才能把细微差别救回来。

要点是：**归一化层是网络里少数几个天然带着「乘一个数、加一个数」结构的地方，所以它是注入条件最省事的接口。**

**它和其他笔记的接口**

具体形态见 [[batchnorm-layernorm]]（BN 竖着切、LN 横着切的那场「横竖之争」）。它也是缓解 [[gradient-vanishing]] 的手段之一：把输入拉回激活函数的非饱和区间，避免导数趋 0 导致梯度一路乘没。

**一句话总结**：归一化是「统一数值量纲」的手段，(x-均值)/标准差 再配可学习的 γ/β，既帮收敛又能缓解梯度消失，但它是调尺度不是降维。
