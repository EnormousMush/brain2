# activation function

**它是什么**  
神经网络里每个神经元算完 `wx + b`（一个线性加权和）之后，套在外面的那个非线性函数。ReLU、sigmoid、tanh 都是它。

**1. 不改变维度**  
输入一个数，输出一个数；输入一个 100 维向量，输出还是 100 维。它只是逐个元素地"掰弯"数值，不动形状。而 SVM 核函数是把低维数据丢到高维空间去（比如二维变无穷维），让原本分不开的点变得能用一刀切开。一个是"原地掰弯"，一个是"搬到更高的楼层"，别搞混。

**2. 唯一理由是引入非线性**  
关键直觉：线性套线性还是线性。  
`W₂(W₁x) = (W₂W₁)x`，两层矩阵乘起来等于一个新矩阵，等于你白叠了。不管叠 100 层，只要中间没有非线性，整个网络等价于一层线性模型——画出来永远是一条直线（一个超平面）。

XOR 就是经典反例：四个点 (0,0)→0, (1,1)→0, (0,1)→1, (1,0)→1，你没法用一条直线把 0 和 1 分开。必须有非线性掰一下才行。

**3. 它是必要条件，不是装饰**  
正因为上面这点，激活函数不是"加了效果更好"的调料，而是"不加就根本没用"的地基。深层网络能拟合复杂函数，全靠这些非线性一层层叠加，把空间反复折叠、拉扯。

**4. 选择要连着梯度消失一起看**  
这是最实战的一点：

- **sigmoid/tanh**：输入一大（正或负），函数值就贴到平的那一段（饱和区），这里的导数趋近于 0。反向传播时梯度是一连串导数相乘，一路乘下来越乘越小，传到前面几层几乎变 0——参数就更新不动了，这就是**梯度消失**。
- **ReLU**：正区间 `f(x)=x`，导数恒等于 1。相乘时"乘 1 不衰减"，梯度能顺畅传到底层。所以它成了默认选项。
