# sft

**一句直觉：它和预训练用的是同一个 loss，只是换了数据**

SFT（监督微调）和预训练用的是完全相同的 next-token loss，区别只有两点：数据换成对话格式，而且 loss 只在 response 部分算（把 prompt 部分 mask 掉，不算它的损失）。

**它教不了新知识，只是在调「格式」**

SFT 的数据量大概 10⁴~10⁶ 条，比预训练小三四个数量级。就凭这点数据，它不可能教会模型新知识，它做的只是调「格式」，把一个疯狂续写的机器，调成一个会规规矩矩答题的助手。

**最关键的推论：SFT 数据放错，就是在教它自信地编**

顺着上面这点有个很要命的推论：如果 SFT 数据里含有模型本来不知道的事实，你不是在教它知识，而是在教它「自信地编造」，因为它只能硬套那个对话格式把不会的东西说得像模像样。这是幻觉的一大来源。

它是 [[rlhf]] 和 [[dpo]] 的起点：reward model 从 SFT 模型初始化，DPO 的 π_ref 就是它。

**一句话总结**：SFT 用和预训练一样的 next-token loss、只在 response 上算，靠少量对话数据调「格式」而非灌知识，所以数据里塞进模型不懂的事实，等于在训练它自信地幻觉。
