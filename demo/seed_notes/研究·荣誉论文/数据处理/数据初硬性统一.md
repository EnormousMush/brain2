## 10s 主规格(所有检测实验)
| 项 | 值 | 为什么 |
| --- | --- | --- |
| 采样率 | **16 kHz** | 编码器输入端统一;>8kHz 内容已被带宽匹配证明不是判别驱动力 |
| 声道 | **mono** | 消除立体声宽度差(立体声特征只在 H2 全长版单独做) |
| 时长 | **10s** | 单窗;人类语料取**歌曲正中**(fma 摘录原样),对齐采样位置 |
| 响度 | **LUFS −23** | 消响度混淆(rms 单特征 45.78% ≈ 瞎猜 = 归一化生效的证据) |
| 容器 | **FLAC** | 无损,杜绝二次有损编码把"压缩痕迹"混进类别信号 |
| 实现 | `part2_analysis/preprocess/audio.py::load_canonical` | 所有导出器共用同一函数 |

**对称处理纪律**:任何变换(低通、mp3 往返、包络匹配、devocal)必须**真假两侧同做**
——不对称处理本身就是可学的标签。

## 衍生规格(H2 全长版)
- 30s 中窗:同链,`offset=(dur−30)/2`(`h2_export.py`);
- 全长:cap 480s、立体声保留、**不做 LUFS**(只用相对响度特征),`fulltrack.py`。
