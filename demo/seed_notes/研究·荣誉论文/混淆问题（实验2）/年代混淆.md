#### 1. 现象:两批数据天生不同年代

|          | 人类侧([[FMA]]-instrumental)           | AI 侧(Suno)         |
| -------- | ----------------------------------- | ------------------ |
| 年代       | 专辑发行中位 **2011**(25%=2009, 75%=2014) | **2026** 生成        |
| 制作       | 独立/lo-fi,母带各异                       | 现代 AI 解码器,统一、干净、明亮 |
| 录音年份可对齐? | **否**——`date_recorded` 仅 5.8% 非空    | —                  |

→ 分类器很可能在学"旧录音 vs 新制作",而不是"人造 vs 真人"。

#### 2. 证据 A — SSL 逐层 EER 的形状(gross-confound 签名)
- **MuQ / MERT 每一层(含 raw 第 0 层)都近 0%** → 几乎任何特征都能把两类分开 = 粗大混淆签名;
- **wav2vec2 早层最好、越深越差** → 判别信号在**低层声学(制作/保真)**,不在高层音乐结构。
  (best test EER:MuQ 0.00% / MERT 0.67% / wav2vec2 1.78% / EnCodec 3.67%)

#### 3. 证据 B — 频谱诊断:Suno 系统性更亮、更满带宽(mel+logreg, n=3998)
各频段 **AI − 人类 平均能量差**:

| 频段 | AI−人类 (dB) | 解读 |
| --- | --- | --- |
| < 500 Hz | +1.3 | 基本持平(LUFS 已控响度) |
| 500–2 kHz | ≈ 0 | 持平 |
| 2–4 kHz | **+4.2** | Suno 更亮 |
| 4–6 kHz | **+6.3** | Suno 更亮 |
| 6–8 kHz | **+5.8** | Suno 更亮 |
| 8–11 kHz | **+7.0** | Suno 高频更满 |

→ **2–8 kHz 整体 Suno 高 ~+5 dB**;低频持平说明**不是响度差**,是**高频/亮度/带宽的制作代差**。

配套两个消融:
- **频段消融**:只留 ≥8 kHz → EER 25%(高频单独较弱);只留 ≤8 kHz → 5%(低-中频承载大部分);
- **低通扫描**:低通到 ≤4 kHz 仍有 **5.83% EER**(几乎等于全带 5.67%)
  → **分离是宽带的,不只在高频**——即使砍掉亮度,低-中频的制作纹理仍能区分。

#### 4. 证据 C — 低层可解释特征(round-1)
- **响度已控**:`rms` EER **45.78% ≈ 瞎猜** → LUFS 归一化生效,响度不是混淆;
- 最强单特征 = **hf>10 kHz**(EER 30.44%,AUC 0.744)→ 再次指向 Suno 更亮/高频更多;
- **8 个可解释特征合起来 → 24.44% EER**,而 SSL 到 0–2%。

#### 5. 综合判断
- 确实存在一个**真实但温和的年代/制作代差**(亮度 + 高频 + 带宽,宽带存在);
- 但 SSL 抓到的东西**远比这 8 个 crude 制作统计丰富**(24% → 0–2%)——
  究竟是"更精细的制作纹理"还是"生成指纹",**尚未分开**,这正是要去混淆才能回答的问题;

#### 6. 控制(带状态)
- [[带宽匹配]](已跑,[phone]):低通 8kHz 后 EER **基本不动**(test 0.11–0.89% → 0.22–1.11%)
  → **>8kHz 高频内容被排除**为驱动力。注意:2–8kHz 内的亮度倾斜(+4~6dB)此刀未削,见下。
- [[编码历史检查]](已跑,[phone]):mp3 128k 统一往返后 EER **完全不动**
  → **编码链/压缩痕迹差异被排除**。
- 打乱标签检查(同批):全层 49–54% ≈ 瞎猜 → **无数据泄漏**,以上结果可信。
- [[频谱包络匹配]](已跑,[phone]):所有频段平均音色拉平后 EER **纹丝不动**
  (匹配后最佳层 0.33%)→ **亮度/倾斜假设彻底排除**。
- [未做] 重建式 de-confounder:[[Afchar 2025]](构造级,最干净)。
- **[已做,[phone]]** era 对齐的现代人类语料 → jamendo2025,见 §9 终审。

#### 7. 当前结论([phone] 更新:便宜载体全部清空)
**响度、genre、泄漏、>8kHz 高频、编码历史、亮度/频谱倾斜(全频段)——全部排除。**
分离信号是**宽带时频纹理**:扛得住低通、mp3 重压、整体音色拉平。剩下两个假设:
1. **深层制作纹理**(2–8kHz 亮度倾斜、动态处理、混音/母带链、噪底特征)——年代混淆的"深水区";
2. **真·生成指纹**(神经解码痕迹)——我们真正想检测的东西。
**分开这两者的手段(亮度部分已杀完):跨生成器测试 + 重建法。**
注:信号扛过了 8k 低通和 mp3 重压 → 如果最终证明是生成指纹,它是个**鲁棒的宽带指纹**,这反而是好消息。

#### 8. 跨生成器矩阵的回响([phone])
[[生成器混淆]] 第 7 节的矩阵给了"深层制作纹理"假设**正面证据**:跨生成器迁移好坏按生成器的

#### 9. 终审:现代人类语料直测([phone],Batch E)——红旗拆除大半

| 测试 | MuQ | MERT | 判读 |
