**"亮度"假设的终审。** [[带宽匹配]] 只砍了 8kHz 以上(结果:不动);但 Suno 在 2–8kHz 还有
+4~6dB 的亮度倾斜没被碰到。这一刀把**所有频段**的平均音色差一次性归零。

#### 干什么(大白话)
给每首歌做一个自动 EQ,把它的**长期平均频谱形状**(整体音色轮廓)拉到**同一条全局标准曲线**。
做完后每首歌的平均音色完全一致——"谁更亮"不再携带类别信息;但每个频段内**能量随时间的波动**
(瞬态、混响尾、噪底质感、解码痕迹)全部保留。**只动"平均",不动"纹理"。**

#### 怎么做(脚本 `diagnostics/spectral_match.py`,已备好并烟测)
1. 两类各采样 300 首,算全局平均包络(mel 域 64 段平滑,固定种子,缓存);
2. 每首:STFT → 自身包络 vs 目标包络的增益曲线(限幅 ±24dB)→ 幅度乘增益、相位不动 → iSTFT;
3. 重抽 MERT 全层特征 → 逐层探针,与原始并排。
- 烟测:两类包络差 1.294 → **0.036**(拉平),同信号纹理相关 **0.999**(纹理保留)。
- 服务器耗时:目标包络 ~10min CPU + 重抽 1–2h GPU;命令在 FUDAN_RUN.local.md 的 Batch 3。

#### 判读(预先写死)
| 匹配后 EER | 结论                                                                     |
| ------- | ---------------------------------------------------------------------- |
| 大幅上升    | 近 0% 主要由亮度/频谱倾斜代差驱动 → 年代混淆主凶找到,频谱匹配进标准预处理                              |
| 基本不动    | **亮度假设彻底排除**(平均音色维度全灭仍可分)→ 信号在时频**纹理**里,交给跨生成器 + 重建法去分"深层制作纹理 vs 生成指纹" |

#### 结果([phone],MERT,6000 clips)
**EER 纹丝不动。** 原始 test 0.11–0.89% → 匹配后 test 0.22–1.00%;匹配后最佳层 layer 2
(val 0.33% / test 0.33%)。

**判读(按预写标准):亮度假设彻底排除。** 每首歌的平均音色被完全拉平后,探针照样近 0%
→ 分离信号**不在平均频谱形状里,在时频纹理里**(能量随时间的波动模式:瞬态/混响尾/噪底/解码痕迹)。

至此**年代混淆的所有便宜载体全部清空**:响度、genre、泄漏、>8kHz、编码历史、亮度/倾斜。
剩下两个假设——**深层制作纹理 vs 真·生成指纹**——由跨生成器测试 + 重建法裁决。见 [[年代混淆]]、[[生成器混淆]]。
