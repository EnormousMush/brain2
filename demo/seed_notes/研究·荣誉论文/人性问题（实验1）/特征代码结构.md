## 一句话
六个"画图脚本改行的提取器"重组为一个 `features/` 包:**一次解码、共享中间量、
一个注册表、一个 CLI**;公式一行未改,新旧对拍逐位一致(diff = 0.00),提速 2.6×;
顺带抓出 features62.csv 里 21 列事故列(ibis_*)并绝版。

## 大修三成果
1. **效率**:解码 6次→2次、HPSS 6次→2次、beat/onset 3次→1次(串行实测 2.57×,
   预注册目标 3× 未达,如实记 —— 剩余成本是 key 家族 11025Hz 历史口径的第二次解码,不能动);
2. **正确性**:①事故列 ibis_00..20(rhythm 顶层原始数组被展开器泄进 CSV,21 列)绝版;
   ②resume 去重键统一 (audio_id, source)(旧 10s 版只按 audio_id,同 id 跨来源会误跳);
   ③列序稳定(旧版靠首行运气);④输入规格从文档变断言(喂错窗长直接报错);
3. **冗余地图**:129 数值列 → 11 真冗余簇(类内验证全过)、可精简 38 列;
   地图落盘 Seagate `5_results/H1_62features/feature_clusters.csv`;
   **提取侧一个不删**(历史可比性),分析侧可选 core 视图(有效特征 ~86)。
   十簇设计冗余:亮度三兄弟 mean/std 各一簇、响度散布三算法、节拍规整三算法、
   量化分三件、onset 两口径、crest 两口径、H/P 两口径、mel 时变 vs mfcc_stds_00、key 两相关。

## 逐文件内部结构

### context.py — FeatureContext
- 口径常量:`SR=22050, HOP=512`(10s 线历史口径);
- 懒缓存属性(第一次要才算,算完缓存,六家族共享):
  `y`(librosa.load 22050 mono)→ `duration` → `hpss`(margin=4)→ `y_harm/y_perc`
  → `beats`(beat_track 于 y_perc)→ `tempo/beat_times`
  → `onset_frames/onset_times`(onset_detect 于 y_perc,delta=0.06 等历史参数)
  → `onset_env_perc`(onset_strength 于 y_perc);
- 注:key 家族不走此对象(历史 11025Hz 口径自己解码,见 families/key.py)。

### registry.py — 三张表
- `SETS`:特征集 → (tag, run函数, mode);tag 兼错误列名(spec_error 等,与历史 CSV 同名);
  mode = "ctx"(共享中间量)/ "path"(模块自己解码);
- `SPEC`:每集输入规格(h1_10s=10s 窗 / h2_mid=30s 窗 / h2_full=全长≥45s),extract 开跑前抽样断言;
- `SKIP_KEYS`:展开器黑名单(旧版漏 "ibis" 酿成事故列,新版补全)。

### extract.py — 唯一 CLI
- 参数:`--set` + (`--data-dir`|`--manifest`) + `--sources --out --workers --limit`;
- 流程:读 manifest → 过滤 → resume(jsonl,键=(audio_id,source))→ spec 抽样断言
  → 进程池(spawn)逐 clip:建 FeatureContext → 按 SETS 依次跑家族 → `_flatten` 落列
  (列名规则与旧版同构:嵌套 dict 加 "stats." 前缀、短数组展开 `_00..`)→ jsonl 增量
  → 收尾重写 CSV(meta 列先行,特征列序稳定);
- 三条等价命令(替换旧三胞胎)写在文件 docstring 里。

### families/(六家族 + H2 两集)
- **spectral.py**:STFT/mel/centroid/rolloff/bandwidth/contrast/HF 能量比/mel 时变
  → `stats.centroid_mean_hz` 等 17 列;
- **timbral.py**:zcr/flatness/mfcc 20×2/delta/chroma 熵/活跃音级/换和弦率/HP 比四件
  → `stats.zcr_mean` 等 53 列;本地 `_trim_to_shortest`(不再依赖捆 matplotlib 的 analysis_utils);
- **dynamics.py**:RMS 六件/crest 四件/响度弧斜率/自相关 → `stats.rms_mean_db` 等 11 列;
- **rhythm.py**:tempo/onset 三件/IBI 三件/切分指数/tempo 稳定度/groove → `stats.tempo_bpm` 等 13 列;
  只返 stats(旧版顶层 ibis 数组 = 事故列来源,已绝版);
- **quantize.py**:自适应细分网格偏差/量化分/swing → `tempo, quantization_score` 等 8 列
  (tempo/num_onsets 与 rhythm 是历史双胞胎列,保留保对拍);
- **key.py**:11025Hz 解码 + HPSS + chroma_cqt + Krumhansl-Schmuckler 相关
  → `best_key/best_corr/alt_key/alt_corr`(alt 缺失合法);
- **midwindow.py / fulltrack.py**:H2 两集原样平移(文件头有平移注记),`run` 即原函数;
- **melody.py / instruments.py**:`NotImplementedError` 占位,扩表时在 SETS 注册**新集**,
  不动既有集 —— 历史列名与数值永远可复现。

### parity_test.py — 验收(可复跑)
- 同 clip 旧路径(复刻旧 one_clip)vs 新路径全列对比;豁免事故列(ibis_*/duration/hop_length);
- 已跑结果:h1_10s 10/10、h2_mid 6/6,最大差 0.00e+00(逐位一致)。
