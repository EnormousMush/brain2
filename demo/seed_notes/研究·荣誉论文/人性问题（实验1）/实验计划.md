## 主线一句话

整个 experiment 1 只回答一个问题:**"AI 音乐里,到底缺了哪些人味?"**
把这个问题分别拿去问两个证人——**机器**(纯统计量)和**人**(耳朵),各录一份证词,
最后让两个证人**对质**:对得上的、对不上的,都是答案。
三幕结束,"什么是音乐中的人性"就从哲学问题变成一张能检验的表。

骨架三句话:**机器先招供(快完了)→ 人再招供(重头戏)→ 对质出真相(高潮)。**

## 第一幕 · 机器的证词(已完成约 80%)

145 个特征,每一个都是一个关于人性的小猜想("人会抢拍""人要换气""人的音色更毛糙"
"人写的歌会好好结尾"…),逐个用纯统计检验:AI 和人类在这一项上真的不一样吗?

**已录完的证词**([[图谱分析 H1]] [[特征图谱分析 H2]] 全案):
- 活下来三类:音色族(AI 渲染味)、散乱类(歌内活跃/戏剧化)、结尾三件套;
- 死掉的更有意思:大部分"不完美"直觉量的是**年代**不是人性(节奏规整/rubato/群体收缩
  ——现代人类自己已经和机器一样了);
- 稳健性已过两审:genre 矩阵(G11)、窗长审计(G12);代码底座大修完毕 [[特征代码结构]]。

**收尾工作**(每件都有一个"为什么"):

| 事 | 为什么 | 成本 |
| --- | --- | --- |
| 体检包:数据查重/泄漏复审/规格残差、降质(mp3 压烂)后 verdicts 存活率、FDR 多重比较校正、bootstrap CI | 防"证词是测量误差编出来的" | 免费~中 |
| **旋律+乐器扩表**(melody/instruments 家族,落点已留在 features/ 包;首推"音准量化度"——音高对 12 平均律网格的偏差,和时值量化分完美对称) | 不补的话,"人味不就在旋律里吗?"一句就问哑了 | 中 |

## 第二幕 · 人的证词(从零开始,P1 重头戏)

同一个问题拿去问人:"你听,这是 AI 吗?你**怎么**听出来的?"直接开问是外行做法,先干两件事:

**1. 先校准仪器(听众可靠性)**——人就是测量仪器,先测仪器稳不稳:
- 同一个人隔 ≥48h 重听同一批,答案还一样吗(test-retest);
- 一群人之间答案散不散(inter-rater 一致性);
- 顺带白捡:疲劳曲线(正确率随题号)、无反馈自学效应。
仪器不稳,后面全是噪声——和机器侧先跑退化测试同一个道理。

**2. 再出好考卷(刺激集设计——两实验的交汇点)**:
- **考题不随机抽,按机器的证词出题**:机器判"AI 味爆表"的、"模糊带"的、"特别像人"的
  各配一定比例,genre/年代/平台配平(实验2 的 confound 教训直接拿来防身)。
  随机抽全是送分题,看不出人的边界;按难度配题,才能看清人在哪种歌上行、哪种歌上不行;
- 哨兵题(明显真/明显假)防敷衍;刺激时长 10s vs 30s 待拍板;规模由功效分析定(初估 100–200 clip)。

**然后才问人,两个讲究**:
- **问不同的人**:路人 / crowd worker / 音乐系学生 / 教授 / 录音师。谁更准是小事,
  **用的线索不一样才是发现**(预注册假设:录音师听渲染,乐手听乐句);
  加 Blase 原话的音乐教授深访(n=3–5,定性线索反哺问卷勾选项);
- **问法多样**:①直球"是不是 AI"+ 信心;②说理由(勾选+自由说;勾选项 = 特征家族
  翻成大白话:"鼓点太准""音色太干净""结尾突兀");③**不问真假只打分**
  ("这首歌的结尾自然吗,1–7")——把人耳变成逐维度传感器,能和机器特征逐条对表。

**执行阶梯**:IRB(现在就启动,周期最长)→ 校内 pilot(n≈10–20)→ 修订 → 正式 crowd(n≥100)→(可选)专家批。

## 第三幕 · 对质(论文的高潮)

两份证词放一张桌上,每个"人味维度"必落四格之一:

| | 人听得出 | 人听不出 |
| --- | --- | --- |
| **机器测得到** | ① 最硬的人味(双方确认) | ② 人类的盲区 |
| **机器测不到** | ③ 人的幻觉(民间传说) | ④ AI 已完全过关 |

- ① 论文能拍胸脯说"这就是音乐中的人性"(候选:结尾三件套?待验证);
- ② 回答"为什么需要机器检测器"——人听不出的地方正是深伪最危险的地方(回哺 P2 的 Discussion);
- ③ 本身是发现:大家以为的"人味"里有多少是传说;
- ④ 给生成器的成绩单:这些维度 AI 赢了。

**四格填完 = "什么是音乐中的人性"的操作性答案 = P1 最后一章 + 主图。**

对质的具体做法:
- 总正确率对表(各人群 vs 单特征阈值 vs 零 ML 投票,同一张考卷);
- **逐题对表**:"人对机错 / 机对人错"的题目画像(它们的特征长什么样?)——P1 最独特的图;
- 线索对表:人说"音色假"的题,音色族的 d 真的大吗?(自述线索 vs 统计可用线索的重合率);
- 群体×线索交互:音乐家 vs 路人用的线索家族不同吗;
- 可选杀手锏(最强证据):**因果验证**——把 AI 歌"被切断"的结尾人工改成自然淡出,
  人的判断翻转吗?翻转了 = 铁证人真在用这条线索。

## 第一幕 v2(正式版)预注册草案([phone] 立;用户四条建议已并入)

**为什么要 v2**:第一幕 v1 是探索(Suno vs 两个人类集、各结论地基都是小样本、
鲁棒性零散做)。v2 = 数据、统计、鲁棒性、特征表四个维度拉满,做成可发表的
"机器证词"正式版;**第二幕在 v2 收口后才开**(考卷按 v2 一级标志物出题),
IRB 并行推进不等 v2。

### 一、数据立方体

**AI 侧 12 家(各 N=1000,全部现成于服务器 crossgen)**:自产六家(同 prompt 协议:
ACE-Step / DiffRhythm 1 / DiffRhythm 2 / LeVo / InspireMusic / Mureka)+ FakeMusicCaps 五家
(MusicGen / AudioLDM2 / MusicLDM / Mustango / Stable Audio Open)+ Suno。
justify:在同一规格下能拿到 ≥1000 首的全部生成器;按架构家族覆盖(LM+连续渲染族 /
DiffRhythm 血统 / 低保真扩散族 / MusicGen 编解码族);开源闭源都有;2023–2025 三代。
SONICS(Suno 老版本 + Udio)因 devocal + 出处问题只进附录。

**人类侧**:主立方体两个千级源——FMA instrumental(2008–17)、jamendo2025
(2024–26,**剔除 E13 的 12 个嫌疑账号后**;建议扩采到 ≥3000 inst,采完先过账号审计);
外部验证行——ccMixter 365、IA netlabels 450(达不到千级,不进主立方体,当 held-out 行)。
justify:沿 P2 证明过的两根轴铺开——年代(2010s vs 2020s)× 平台生态(策展 CC /
开放平台 / remix 社区 / netlabel)。

**每格同量**:主立方体每格 N=1000(FMA、jamendo 分层重抽到 1000);统计上 d/CI 不要求
等量,但立方体判决要公平必须同量。

**对齐轴(鲁棒性电池之外)**:
- genre:主数字用 8-genre 分层配平重抽(AI 侧本就 125/genre,人类侧按标签配平);
- 年代:不对齐,当分层(它是被观察的变量);
- 内容/prompt:自产六家同 prompt(内容锁死)vs FMC 五家 caption 生成(内容不同)——当分层标注,不混报;
- 平台生态:无法对齐,当分层;
- 窗长分层:10s 特征全语料;30s/全长特征只在有全曲的语料(suno / jamendo / 自产六家),
  每个标志物标明验证层级;
- 人声:全部 instrumental;响度/格式:common spec。

**分开讨论 = 判据本身**:先报全池判决,再报按 genre / 年代 / 内容协议 / 家族的分层判决;
一级标志物必须在各分层里不翻号。

### 二、统计协议(预注册)

**三类比较**(缺一不可,否则分不清"AI 共性"与"某一家/某一源的怪癖"):
1. AI–人类:12 家 × 2 千级人类源(+ 外部行)——判"有没有差";
2. AI–AI:每家 vs 其余 11 家池(必要时族 vs 族)——判"差是否某家/某族独有";
3. 人类–人类:FMA vs jamendo(+ 外部行)——判"差是否某个人类源的语料味"。
每格:Cohen's d + bootstrap 95% CI;全表 FDR;genre 分层 d。

**判决树(每个特征走一遍)**:
1. 人类–人类先看:若人类源之间已分得开(|d| ≥ 0.5),该特征带年代/平台味——不得进
   "人味"一级,除非 AI-vs-每个人类源 都同号且幅度更大;
2. AI–人类:数几家生成器显著同号(对每个人类源分别数);
3. AI–AI:某家/某族显著异于其余 → 标"生成器特有 / 家族级"。

**五桶 + 空**:
- 通用人味:≥9/12 家 × 2 个千级人类源同号显著,分层不翻,人类–人类不分;
- 家族级:某一架构族同号、其余族不同(回哺 P2 家族结论);
- 生成器特有:仅 1–2 家(如 Suno-only 的结尾三件套候选);
- 人类源特异:某人类源独异(排除出人味 claim,记为语料学发现);
- 方向不一致:分层翻号(jazz 反转类);
- 空:|d|<0.2 或不显著。
"AI 通用"与"人类通用"是同一组比较的两面,靠 AI–AI 与人类–人类两类比较区分。

**开跑前押注**(待填):结尾三件套押"生成器特有或家族级(截停是产品行为)";
音色族押"通用人味";散乱类押"方向不一致(jazz)";节奏/量化族押"空或人类源特异(年代)";
副歌复制押"通用(现代人类复制粘贴)"。输了照写。
