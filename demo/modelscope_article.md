# brain2：把几个知识库放在一起，让它们互相提问

团队：brain2　日期：2026-09-06

## 我们想解决什么

很多人的笔记分散在不同的库里：工作一个、论文一个、生活一个。每个库自己都很整齐，但库和库之间从来不说话。一个在混音笔记里写过的"先做减法再做加法"，很可能对论文写作也有用，只是没人把它们摆到一起。

brain2 做的事就是把这些库摆到一起。每个库叫一个副脑。系统定期在副脑之间寻找相关但不相同的内容，把它们拼成一个可以讨论的题目，再让四个不同角色围着这个题目辩论几轮，最后把有用的结论记成卡片。

## 主要功能

- 导入：Markdown、Word、PDF、HTML、整个 Obsidian 文件夹或 zip，导入过程分五步显示进度。
- 星图：每个副脑是一个星球，碎片围绕它分布，副脑之间按共现关系连线。可以点击碎片、想法和卡片看它们对应的原文。
- 夜间发现：后台按设定的频率在副脑之间搜索，找到的想法进入收件箱，用户滑动保留或丢弃。
- 辩论：四个角色（提议者、怀疑者、类比者、裁判）围绕题目发言，每一条反驳都标出它反驳的是谁的哪一句。
- 卡片：辩论结束后得到几张结论卡，回放时星图上会把卡片引用的碎片连起来。

## 技术

- 后端 FastAPI，数据库 MongoDB，没有 MongoDB 时自动切到内存存储。
- 检索用向量相似度，但只取中间相似度区间的结果，太像和完全无关的都不要。
- 模型接口兼容 OpenAI 格式，可直接填魔搭 API-Inference 的地址，使用 Qwen3 对话模型和 Qwen3-Embedding 或 bge-m3 做向量。
- 前端 React 和 three.js，星图用 3D 力导向布局。
