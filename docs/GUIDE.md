# brain2 使用指南

这份指南按你第一次打开 brain2 的顺序写。读完大约需要十分钟。

## 1. 启动

最省事的方式是离线模式，不需要任何账号或 Key：

```bash
OFFLINE=1 ./run.sh
```

打开 http://localhost:5173 。离线模式下所有模型调用返回固定的假结果，辩论内容没有意义，但界面、导入、星图、收件箱都能正常操作，适合先熟悉流程。

要看到真正的辩论，需要两样东西：一个 MongoDB（可选，没有就用内存存储，重启清空）和一个模型 Key（必需）。第 3 节讲怎么配。

## 2. 界面

打开后看到的是星图。四个区域：

- 顶栏：左边是 brain2 标志，点它随时回到星图。右边两个按钮：导入笔记、切换深浅色。
- 左侧竖排图标：星图、发现（右上角数字是收件箱里待处理的题目数）、出题、设置。
- 右侧：每个副脑的碎片数量。点击某个想法后，这里显示它命中了哪些副脑。
- 右下角的小按钮：灵光，随手记一句话。

星图里每个球是一个副脑，球的大小和它的碎片数量有关。滚轮缩放，拖动旋转，不动的时候它会自己慢慢转。点空白处或按 Esc 取消当前选中。

星图上方有一个切换：副脑 / 碎片。切到碎片会把每条笔记显示成围绕副脑的小点，点一个小点可以看原文。

## 3. 配置模型

点左侧的设置图标。

1. 点一个预设（魔搭、OpenAI、DeepSeek、Kimi、通义千问、Claude、Ollama本地），或者手动填。
2. 填 api_key。base_url 和模型名预设已经填好，需要的话可以改。
3. 向量模型：至少一个提供方要有向量模型，导入笔记时用它。魔搭、OpenAI、通义千问和 Ollama 的预设自带；DeepSeek 和 Kimi 没有向量接口，要再加一个有向量的提供方。
4. 保存。

Key 只存在你自己的数据库里，不会发到别处。

推荐配置：魔搭预设，免费额度够试用，对话用 Qwen3，向量用 Qwen3-Embedding。

## 4. 导入笔记

点顶栏的导入按钮。三种来源：

- 文件：选一个或多个 md、txt、csv、docx、pdf、html 文件，或者一个 zip。
- 文件夹：直接选一个 Obsidian 库或 Notion 导出目录。会自动跳过 .obsidian、.trash 等配置目录。
- 粘贴：一段文字。

选好后给这个副脑起名。建议用"领域·主题"的格式，例如"工作·系统设计"、"阅读·经济学"，星图上标签短一些好看。

导入分五步显示进度：读取、切分、向量化、聚类、布局。几十条笔记几秒钟，几百条大概一分钟，主要时间在向量化。

导入完成会显示碎片数和主题数。碎片是切分后的段落，一条笔记可能被切成几段；主题是聚类后的分组。

**至少导入两个副脑**。brain2 的核心是在不同副脑之间找联系，只有一个副脑什么也不会发生。副脑之间差别越大，出来的题目越有意思。

## 5. 发现

发现是 brain2 自己在副脑之间找题目。点左侧的发现图标。

页面上方是设置：

- 模式：关闭 / 只递给我 / 自动开庭。"只递给我"是找到题目放进收件箱等你处理；"自动开庭"是找到题目直接辩论，结果连同卡片一起放进收件箱。
- 频率：多久跑一次。
- 立即运行：不等定时，现在跑一次。

收件箱里每张卡是一个题目，上面标着它来自哪两个副脑。左滑丢弃，右滑保留，或者点按钮。保留的题目可以点"开始辩论"。

不想让某个副脑参与发现，在设置里可以把它排除。

## 6. 出题和辩论

不想等发现，自己出题也可以。点左侧的出题图标，输入一个问题，选一个"跳跃度"：低是找很接近的内容，高是找隔得远的。系统会先显示它检索到了哪些碎片，确认后开始辩论。

辩论页四个角色轮流发言：

- 提议者：把两个副脑的内容接在一起，提出一个主张。
- 怀疑者：找主张的漏洞。
- 类比者：换一个领域重新说一遍。
- 裁判：判断是否继续，或者结束。

每条发言上如果有"反驳 01.02"这样的标记，表示它反驳的是第一轮第二条发言。发言里引用的碎片可以点，星图上会亮出来。

辩论停下来有三种原因：意见趋同、用完预算、到达轮数。之后下方出现卡片。

## 7. 卡片

卡片是辩论的结论，每张附带它依据的碎片。点"回放"回到星图，卡片引用的碎片之间会连线。卡片可以编辑，改完保存。

## 8. 灵光

右下角的小按钮。随手记一句话，它会被存成一条想法，出现在星图上，并参与之后的发现。适合记录突然想到的东西。

## 9. 数据

- 所有数据在你自己的 MongoDB 里（或者内存里）。
- 删除一个副脑：设置里选中它删除。它的碎片、向量、相关辩论和卡片一起删除，不可恢复。
- 删除全部：设置里最下面。提供方配置保留，其他全部清空。
- 换电脑：备份 MongoDB 的 weave 数据库即可。

## 10. 常见问题

**星图是空的。** 还没有导入任何副脑，或者后端没起来。看终端里有没有报错，访问 http://localhost:8000/api/health 看后端是否在。

**导入卡在向量化。** 检查设置里有没有配向量模型，以及 Key 是否有效。离线模式不需要。

**发现一直没有新题目。** 只有一个副脑；或者副脑内容太接近；或者模式是关闭。试试"立即运行"看终端日志。

**辩论内容像胡说。** 你在离线模式。配一个真实模型的 Key。

**重启后数据没了。** 没有连上 MongoDB，用的是内存存储。启动时终端会有提示。装一个 MongoDB 再启动。

**PDF 导入后内容乱。** 扫描版 PDF 没有文字层，目前不做 OCR。先用别的工具转成文字再导入。

**中文以外的笔记可以吗。** 可以，切分和检索不依赖语言。界面是中文的。
